1. Поля с конкретными значениями. Абстрактный класс — плюс. Интерфейс — минус для полей экземпляра, плюс для статических полей. Класс может хранить отдельное значение для каждого объекта. В интерфейсе поля могут быть только статическими.

2. Конструктор. Абстрактный класс — плюс. Интерфейс — минус. Конструктор абстрактного класса вызывается при создании объекта наследника. У интерфейса нет конструктора экземпляра.

3. Наследование или реализация нескольких типов. Абстрактный класс — минус. Интерфейс — плюс. У класса может быть один базовый класс и несколько интерфейсов.

4. Готовая реализация метода. Абстрактный класс — плюс. Интерфейс — плюс. В абстрактном классе можно написать тело метода. В интерфейсе это тоже возможно начиная с C# 8.

5. Свойства без реализации. Абстрактный класс — плюс. Интерфейс — плюс. Оба могут объявить свойство, которое реализует конкретный класс.

6. Использование как типа поля или переменной. Абстрактный класс — плюс. Интерфейс — плюс. В такой переменной можно хранить объект класса-наследника или класса, который реализует интерфейс.

7. Наследование классов. Абстрактный класс — плюс. Интерфейс — минус. Абстрактный класс может наследовать другой класс, а интерфейс — другие интерфейсы.

8. Приватные методы. Абстрактный класс — плюс. Интерфейс — плюс. В обоих случаях приватные методы можно использовать внутри самого типа. Для интерфейсов это доступно начиная с C# 8.
